# HNC Input Table

Place the Γ=50, κ=1 WLP-regularized HNC table here as:

```text
k,S,c_short
0.000000,0.001234,-0.123456
...
```

Accepted header aliases:

- `k`, `k_grid`, `K_GRID`
- `S`, `S_k`, `S_K`
- `c_short`, `C_K_SHORT`, `cshort`

`c_short` must be the short-range WLP-regularized direct correlation function,
not the full HNC direct correlation containing the bare Yukawa tail.
